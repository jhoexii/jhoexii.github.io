Kung walang “Allow USB debugging?”
1) Unlock TARGET phone.
2) Developer options → USB debugging ON.
3) Developer options → Revoke USB debugging authorizations.
4) Turn USB debugging OFF, wait a few seconds, then ON again.
5) Unplug/replug OTG and press CONNECT again.
6) If Android asks USB mode, choose File transfer.

The browser USB chooser and Android RSA authorization are separate permissions.
